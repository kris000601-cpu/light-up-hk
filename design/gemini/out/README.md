做法備忘：
- 每次請求要明說「generate the image」，不然它有時只回 SVG 代碼；請求發出後一分鐘沒有回答框，就刷新頁面再發。
- 模型選「4 Neon」+ 思考等級「高」（輸入框右邊的選單；刷新頁面後要檢查）。
- **怎樣存原圖**：按圖片右上角「下載完整尺寸的圖片」（或在頁面裏用腳本按最後一個回答的這個按鈕），內置瀏覽器會把 2048×2048 的 JPEG 存到 `C:\Users\chris\Downloads\`，檔名是一串亂碼 `.tmp`；搬過來改名 `sNNN.jpg`。不要用頁面裏顯示的圖（只有 1024、還是 webp），也不要直接下載 lh3 網址（多數要登入，403）。
- 頁面的網絡請求記錄只留 250 條，記滿了就找不到新圖的網址，所以不要靠它。
- 它常犯的錯：背景加東西（高樓、山、旗）、線條變細、海 / 陸底座弄錯、山脊兩頭懸空。逐張縮到 66 像素檢查，錯了就指出哪條規則、叫它重畫。
