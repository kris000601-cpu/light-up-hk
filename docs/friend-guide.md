# 給朋友的使用說明（草稿，2026-11-20）

M2 實地測試通過後，由 Chris 用 WhatsApp 發給朋友。朋友是香港人，所以用港式繁體書面語；要改廣東話口語再改。介面文字改了的話，這裏要跟着改（「加至主畫面」「匯出備份」「你已到達」「帶我去」）。

---

**「點亮香港」測試版，想請你幫我試試**

這是我做的一個小 App：去到香港不同地方，在現場「蓋章」，慢慢把 18 區點亮。
https://kris000601-cpu.github.io/light-up-hk/

**① 先加到主畫面（請先做這步再蓋章）**
・iPhone：用 Safari 打開 → 按下方的分享按鈕 → 選「加至主畫面」，之後都從主畫面的「點亮香港」打開。在 Safari 裏蓋的章，主畫面那個是看不到的。
・Android：用 Chrome 打開 → 右上角「⋮」→「加到主畫面」或「安裝應用程式」。

**② 蓋章**
打開後是一張空白的紙，按正中那一點，允許讀取位置，附近的景點就會浮出來。已經到了的話，正中會有一個紅章寫着「你已到達」：按它，再用手指按住紙面約一秒，「咔嗒」一聲就蓋好了。還沒到的景點，按一下可以「帶我去」。

**③ 記得備份**
不用註冊帳號，章只存在你的手機裏。蓋了幾個之後，到「我的」→「匯出備份」，存到「檔案」或傳給自己。

App 只在你按那一點時讀一次位置，不會在背後追蹤你。試的時候覺得哪裏不順、看不明白、到了卻蓋不到，截圖再說一下你在哪裏，傳給我就可以了，多謝！
