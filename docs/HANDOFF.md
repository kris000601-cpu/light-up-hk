## 1. 一句話說明

一個竪屏手機 App：香港 18 區地圖一開始全被遮住，你實際去過一個地方，就在現場「蓋章」把它點亮，慢慢集齊全港。目標是讓住在香港的人走出自己常去的幾個區，更了解香港。

**起源**：Chris 在香港住了 7 年，住將軍澳、在中環上班，去行龍脊時才發現柴灣、小西灣這些地方從來沒去過。問過土生土長的香港朋友，也一樣（例如住旺角的朋友沒去過紅磡海濱）。

**第一階段目標**：先做給自己和朋友玩，不考慮商業化。

## 3. 資訊架構

```
全港地圖（18 區，按進度上色）
 └─ 點一個區 → 撥雲見霧動畫
     └─ 區地圖（細分成約 5–10 個「地方」，沒去過的蓋著霧）
         └─ 每個地方 / 景點卡片
             ├─ 已蓋章：顯示日期、照片
             ├─ 人在附近：顯示「蓋章」按鈕
             └─ 沒去過：問號 + 「導航」按鈕（跳到 Google Maps）
印章冊
 ├─ 區章（18 枚，按港島 / 九龍 / 新界及離島分組）
 └─ 景點章
我的
```

**例子**：去炮台山只會點亮東區裡的「炮台山」這一塊，不會整個東區都亮起來。東區的示意細分是：炮台山、北角、鰂魚涌、太古、西灣河、筲箕灣、柴灣、小西灣、柏架山 · 大潭。

六個畫面：

1. **地圖首頁**：頂部「8 / 18 區已點亮」和 18 格進度條；18 區地圖；附近可蓋章的卡片；離你最近的未點亮區。
2. **區詳情（東區）**：大圓印章、2 / 5 景點、5 張景點卡片（已蓋章 / 可蓋章 / 未去過三種狀態）、補錄按鈕。
3. **蓋章瞬間**：郵戳式紅色印章（地名 + 日期）、拍照留念、生成分享卡片。
4. **印章冊**：18 枚區章，集齊的區是金章，沒去過的是虛線加問號（借鑒寶可夢圖鑑的剪影）。
5. **進入東區 · 撥雲見霧**：區內細分地圖，沒去過的地方蓋著霧；打開時有雲散開的 CSS 動畫。分塊是**示意**，不是真實邊界。
6. **和風金雲地圖**：首頁的另一種風格。靈感來自日本屏風畫裡的金雲：沒去過的區蓋金雲，點亮後蓋一枚朱印，集齊的區整塊變朱色；「下一站」做成車票樣式。

**還沒定**：首頁用第 1 屏（現代風）還是第 6 屏（和風金雲）。我的建議是首頁用金雲，印章冊改成日本那種「方塊地圖」（每區一樣大的格子）。要等 Chris 決定。

## 5. 數據

### 5.1 景點清單：`data/spots.csv` / `data/spots.json`

- 87 個景點，18 區每區 3–6 個。內容一樣，CSV 方便 Chris 用 Excel 改，JSON 給程序讀。
- 欄位：`id, district, area（小地名）, name, tip（一句推薦）, lat, lng, kind（類型）, verified`
- ⚠️ **座標是估的近似值，全部 `verified: false`。** 做蓋章功能之前必須逐個核對，否則人到了也蓋不到章。可以用 Google Maps 或 OpenStreetMap Nominatim 核對。
- 已知有爭議的：獅子山山頂在黃大仙和沙田的交界；紅磡海濱長廊靠尖東那段其實屬油尖旺。
- 以 CSV 為準。改了 CSV 之後要重新生成 JSON（可以寫個小腳本）。

### 5.2 地圖邊界：`data/hk18-simplified.geojson`

- 18 區的**簡化**邊界，來源是 ECharts 4.9.0 npm 包裡的 `map/json/province/xianggang.json`，用 `tools/decode_echarts_map.py` 解碼。區名已經轉成繁體。
- 精度很低，只夠畫風格化的總覽圖，**不能用來判斷「人在不在某一區」**。
- **要換成官方數據**（之前的雲端環境連不上 data.gov.hk，在本機可以下載）：
  - 18 區界：DATA.GOV.HK →「區議會分區界線」（地政總署 / 選管會）
  - 細分「地方」：2019 年區議會選區（全港 452 個，大致按屋苑、街區劃分）。合併成約 100–150 個香港人熟悉的地名（炮台山、太古、杏花邨……）。合併對照表要另外做一份，建議放在 `data/areas.csv`（欄位：選區代號 → 地方名 → 所屬區）。
  - 下載後用 mapshaper 簡化，再轉成 TopoJSON 減小體積。

## 6. 技術方案（全免費）

| 需求 | 方案 |
| --- | --- |
| App 形式 | 網頁 App（PWA），手機瀏覽器打開，可以「加到主畫面」。暫時不上架 App Store（每年 99 美元） |
| 框架 | 建議 Vite + React + TypeScript。Chris 是新手，選 AI 最熟悉的工具組合 |
| 地圖 | 自己用 SVG 畫（d3-geo 做投影），風格完全可控，不需要地圖服務 |
| 定位 | 瀏覽器自帶的 `navigator.geolocation.getCurrentPosition`，只在按按鈕時調用。**必須用 https**（localhost 除外） |
| 判斷範圍 | 景點：在手機上直接算距離（haversine），300 米以內就算到了。地方：`@turf/boolean-point-in-polygon` |
| 數據存儲 | 第一版存在手機本地（IndexedDB，可以用 `idb-keyval`）。之後要跟朋友互相看，再加 Supabase（有免費額度） |
| 照片 | 第一版存本地 IndexedDB，記得壓縮 |
| 導航 | 跳轉連結 `https://www.google.com/maps/search/?api=1&query=<lat>,<lng>` |
| 托管 | GitHub Pages 或 Cloudflare Pages，免費，自帶 https |
| 動畫 | 撥雲見霧用 CSS 動畫或 Framer Motion；要支持 `prefers-reduced-motion` |

**GPS 的注意點**：高樓之間定位可能偏差幾十米，所以景點半徑不要小於 200 米；第一次使用時 iPhone 會彈窗問定位權限，要寫好說明文字；朋友之間玩，暫時不需要防作弊。

## 7. 建議的開發順序

1. **M0 搭架子**：Vite + React + TS 項目、PWA 設定、繁體字體、部署到 GitHub Pages，先跑通一個能在手機上打開的空殼。
2. **M1 全港地圖**：讀 GeoJSON 畫 18 區，按進度上色，點區進入區詳情（先用假的進度數據）。
3. **M2 蓋章**：讀定位 → 找附近景點 → 蓋章 → 存到 IndexedDB → 蓋章動畫 → 印章冊。**這一步做完就可以給朋友試用。**
4. **M3 細分地方**：換成官方區界 + 選區合併數據，加區內地圖和撥雲見霧動畫，加「到此一遊」。
5. **M4 補錄、拍照、分享卡片**：分享卡片生成 9:16 的 IG Story 圖片。
6. **M5 朋友**：Supabase 帳號，看朋友的地圖（不做排行榜）。

每完成一步都部署一次，讓 Chris 用手機試。

## 9. 調研摘要（決策依據）

- **Fog of World**：後台 GPS 自動去霧，3,100 多個評分，平均 4.8，30 美元買斷；用戶主要抱怨耗電 → 我們不做後台追蹤。
- **日本經縣值（Keikenchi）**：手動給每個縣打 0–5 級（住過、過夜、逛過、踏足、路過），地圖按等級上色，可以導出分享圖 → 用顏色深淺表示進度。
- **Wandrer**：按走過的街道百分比計算進度，最後 10% 最難，也最上癮。
- **美國國家公園護照**：在每個公園蓋實體章，章上有日期。
- **日本井蓋卡、御朱印、車站印章**：只能在現場拿到，每處設計不同 → 章只能在現場蓋。
- **洛中洛外圖的金雲** → 用來遮住未探索的區域；**日本 47 都道府縣方塊圖** → 每區一樣大的格子，避免離島很大、油尖旺很小。
- **寶可夢圖鑑**：沒收集到的顯示剪影 → 用問號製造好奇。
- **Foursquare**：靠積分和市長頭銜推動簽到，新鮮感一過用戶就流失 → 不做積分和排行榜。
- **香港本地**：沒有同類的收集型 App。現有的是導覽 App（ExploreHK，21 個景點）和浸大學生做的 18 區故事地圖（TYR）。
